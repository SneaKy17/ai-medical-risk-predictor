# 🩺 AI Medical Risk Predictor

## 🚀 Overview
An AI-powered healthcare assistant designed to help doctors and healthcare workers quickly assess disease risk using patient data.

## 💡 Key Features
- 🔍 Real-time disease risk prediction
- 🎨 Interactive Streamlit dashboard
- 📊 Health indicators visualization
- ⚡ Fast and lightweight backend using Flask
- 🧠 Machine Learning model (Scikit-learn)

## 🧱 Project Structure
backend/ → Flask API + ML model  
frontend/ → Streamlit UI  

## ⚙️ Tech Stack
- Python
- Flask
- Streamlit
- Scikit-learn
- NumPy / Pandas

## ▶️ How to Run

### 1. Clone repo
git clone https://github.com/Sneaky17/ai-medical-risk-predictor.git

### 2. Install dependencies
pip install -r requirements.txt

### 3. Run backend
cd backend/app  
python main.py  

### 4. Run frontend
cd frontend  
streamlit run app.py  

## 🎯 Impact
This system assists doctors in early diagnosis and helps improve healthcare accessibility, especially in rural areas.
