# 🩺 AI Medical Risk Predictor

## 🚀 Overview
AI-powered system to assist doctors in early disease risk prediction using patient health data.

## 💡 Features
- Machine Learning prediction
- Streamlit interactive UI
- Real-time health risk analysis
- Easy-to-use interface

## ⚙️ Tech Stack
- Python
- Flask
- Streamlit
- Scikit-learn

## ▶️ How to Run

### Backend
cd backend/app
python main.py

### Frontend
cd frontend
streamlit run app.py

## ⚠️ Disclaimer
This system assists doctors and does not replace medical advice.
